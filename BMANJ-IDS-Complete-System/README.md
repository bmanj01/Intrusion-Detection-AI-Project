# BMANJ IDS Complete System

This package combines both source repositories into a single deliverable for submission and zipping.

## Included Projects

### `ai-backend`
Source from `https://github.com/bmanj01/Intrusion-Detection-AI-Project`

- Python-based intrusion detection training and inference project
- Includes model artifacts, training scripts, evaluation scripts, and FastAPI serving code
- Source commit used: `331ef27`

### `web-frontend`
Source from `https://github.com/bmanj01/v0-bmanj-ids-system`

- Next.js dashboard and frontend system for the IDS project
- Includes app routes, UI components, styles, and supporting scripts
- Source commit used: `0fa4ec1`
